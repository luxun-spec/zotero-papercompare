# Changelog

## 0.1.0 — 2026-10-16

Initial preview release.

- Compare multiple papers and experiment configurations in Zotero.
- General, AI Infra and custom field templates.
- Manually link saved PDF highlights as traceable evidence.
- Keep source quotes and page labels; navigate to original annotations.
- Export Markdown and CSV; back up and import complete JSON data.
- Atomic local storage with previous-state backup and recovery.
- Chinese/English UI and dark mode.

Verified locally on Windows with Zotero 10.0.6. Earlier versions and macOS/Linux GUI are not verified. No AI API key is required. JSON backups do not include PDFs or remap source items across machines.
